Thank you for helping! Google needs 12 people to test the app for 14 days before it can go on the Play Store. Testing is free: you'll get a code, so you won't pay the US$4.99.

Before you start

  • You need an Android phone. The app is made for the Galaxy Z Fold, but it works on any phone.
  • Use the same Google account for every step, the one your phone's Play Store uses.
  • You'll get your own code from me, bunsoootchi, in a DM. Each code works once, so please don't share it.

If something goes wrong

The testing page says the app isn't available

Join the group first (step 1), with the same Google account. It can take a few minutes after joining.

The code doesn't work

Check that you typed it exactly, and that you're using the same Google account. Each code works only once. If it still fails, message me for a new one.

I have more than one Google account

In the Play Store, tap your profile picture and switch to the account you used for the group before you redeem and install.

I had the old version from GitHub

You don't need to uninstall it. The Play version should install right over it and keep your books, progress, and stickers.
